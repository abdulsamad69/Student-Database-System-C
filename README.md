Student Database System in C
A simple, lightweight command-line application built during my 1st semester to manage student records. This project demonstrates the core concepts of procedural programming, structures, and file handling in C.
🚀 Features
Add Student Records: Dynamically takes student inputs (Name, Roll Number, and Marks).
Persistent Storage: Saves data securely in a structural format inside a standard text file (`students.txt`) using file append mode.
Robust Error Handling: Validates file streams to ensure data safety.
🛠️ Tech Stack
Language: C (compiled with GCC)
Concepts Used: Structures, File I/O (File Handling), Standard Input/Output streams.
📁 Project Structure
`StudentDataBase.cpp`: Main source code containing the logic.
`students.txt`: Output text file where data is appended and stored.
